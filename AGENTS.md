# Agent Workflow

- Before editing, inspect the relevant files and search for existing implementations or patterns.
- For substantial tasks, present a brief plan and wait for approval before making changes.
- Work only on the currently agreed stage; do not implement future stages.
- Modify only files necessary for the requested task.
- Do not add dependencies without a clear need and explicit approval.
- Preserve user changes; do not remove or overwrite work you did not create.
- Do not run destructive commands without explicit approval.
- After changes, run relevant existing checks when appropriate, such as `npm run build` and `git diff --check`.
- Report only checks that were actually run; do not claim unrun tests passed.
- Summarize changed files, the changes made, and the results of checks.
- Do not commit, push, or make remote repository changes without explicit instruction.
- Ask before implementing when requirements are ambiguous or require a significant architectural decision.
